# 练习：基础查询与过滤

## 业务背景

在电商订单系统中，客服系统可能需要筛选由于异常原因被系统判定为“非活跃”（`status = 0`）的早期注册用户（假设用户 ID 在 `1` 到 `10` 之间），并核对他们的用户名，以便进行人工回访。

## 任务要求

请在 `exercise.sql` 中编写 SQL 语句，完成以下任务：
1. 从 `users` 表中筛选出 `status = 0`（非活跃）且 `id` 在 `1` 到 `10` 之间（**闭区间**）的所有用户。
2. 仅投影（选择）`id` 和 `username` 两个字段，且将 `username` 别名定义为 `user_name`。
3. 请将结果按照 `id` 从小到大排序（使用 `ORDER BY id`），以确保测试输出的稳定性。

