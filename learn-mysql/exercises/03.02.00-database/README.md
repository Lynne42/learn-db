# 练习：数据库管理

## 业务背景

我们在开发和运维数据库时，需要频繁管理各种测试库和正式库的声明期。为了确保部署脚本能重复运行而不报错，也为了统一字符编码规范，本节练习将带你使用 DDL 语句对数据库进行防错性创建和属性修改。

## 任务要求

请在 `exercise.sql` 中编写 SQL 语句，完成以下两项任务：

1. **防错性创建**：使用安全写法，创建一个名为 `temp_test_db` 的测试数据库，并显式指定其默认字符集为 `utf8mb4`，默认排序规则为 `utf8mb4_bin`。
2. **属性修改**：编写修改数据库语句，将该测试库 `temp_test_db` 的默认排序规则变更为 `utf8mb4_unicode_ci`（字符集仍需保持为 `utf8mb4`）。

> ⚠️ **重要提示**：请在建表或修改语句后**不要**编写 `DROP DATABASE`，否则测试脚本将无法提取并校验你的库属性。

## 如何验证

请在终端进入本目录，然后执行：
```bash
bash test.sh
```
如果输出 "✅ 测试通过！"，则说明你已掌握本节内容。可以接着向 Agent 发送 `/db.check` 来登记进度。
