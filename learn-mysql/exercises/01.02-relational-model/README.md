# 练习 02: 实体关系设计判断

## 任务目标
检验你是否真正理解了 1:N 与 N:M 关系的模型映射。

## 题目说明
在一个标准的电商系统中，请判断以下两个场景分别属于什么关系模式（一对一、一对多、多对多）：
1. 【用户】与【订单】之间的关系是：_______
2. 【订单】与【商品】之间的关系是：_______

请打开 `exercise.txt` 文件，在对应的横线处填写你的答案。填写时请使用标准缩写词（如 `1:1`, `1:N`, `N:M`）或者中文短语（如 `一对一`, `一对多`, `多对多`）。
