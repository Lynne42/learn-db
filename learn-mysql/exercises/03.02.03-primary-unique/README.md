# 练习：主键与唯一键

## 业务背景

我们之前创建的 `users` 基础表中，只指定了 `id` 为自增主键。而用户名 `username` 和邮箱 `email` 都只是普通的数据列。这导致多名用户可以同时使用完全相同的用户名或邮箱进行注册，给系统业务带来了逻辑混乱。

为了解决这一问题，我们需要在数据库底层构筑唯一性防线，通过 `ALTER TABLE` 语句为这两个字段追加唯一键约束。

## 任务要求

请在 `exercise.sql` 中编写 SQL 语句，完成以下两项任务：

1. **用户名唯一**：使用 `ALTER TABLE` 为 `users` 表的 `username` 字段添加唯一性约束，并将该约束命名为 `uk_users_username`。
2. **邮箱唯一**：使用 `ALTER TABLE` 为 `users` 表的 `email` 字段添加唯一性约束，并将该约束命名为 `uk_users_email`。
