# 练习 05: 变量分配与标识符转义

## 任务目标
检验你对用户变量 (`@`) 以及标识符反引号 (```) 、字符串单引号 (`'`) 的综合运用。

## 题目说明
请打开本目录下的 `exercise.sql` 脚本文件，编写两行 SQL 代码：

1. **第一行**：声明一个用户变量 `@current_env`，并将其赋值为字符串 `'production'`。
2. **第二行**：使用 `SELECT` 语句查询出这个变量的值，并且为这一列起一个带有空格的别名，名为 `App Environment`（提示：有空格的别名属于特殊标识符，需要用哪个符号包裹？）。
