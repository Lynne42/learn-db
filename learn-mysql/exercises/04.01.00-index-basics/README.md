# 练习：索引原理与创建

## 业务背景

随着我们电商系统用户注册量的攀升，后台客服系统在按照注册时间（`created_at` 字段）检索或统计用户列表时遇到了明显的响应延迟。经过性能排查，发现这部分查询由于缺少对应的物理索引支撑，每次都触发了昂贵的“全表扫描”（`ALL`）。

为了提高检索效率，我们需要在 `users` 表的 `created_at` 字段上创建一个普通的二级索引。

## 任务要求

请在 `exercise.sql` 中编写 SQL 语句，完成以下任务：

- 使用 `CREATE INDEX` 语法为 `users` 表的 `created_at` 字段创建一个普通二级索引。
- 该索引的命名必须为：`idx_users_created_at`。
