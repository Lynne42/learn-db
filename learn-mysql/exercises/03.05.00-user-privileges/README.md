# 练习：账户与权限管理

## 业务背景

订单报表服务需要读取隔离练习数据库，但不能写入数据。本练习先模拟误授予 `INSERT`，再使用 `REVOKE` 将账户收敛为数据库级只读权限。

## 涉及的数据表

涉及的数据表：无。

本题操作 MySQL 实例级账户及数据库级权限，不读取或修改业务表。授权范围是测试脚本创建的隔离数据库 `order_system_lesson_030500.*`。

**表关系：** 无。

## 测试数据说明

本题不导入业务数据。测试器会重建空的隔离数据库，并在执行前、退出时清理专用账户 `'order_reporter_030500'@'%'`。账户是实例级对象，因此不要修改账户名或 Host。

## 任务要求

在 `exercise.sql` 中按顺序完成：

1. 创建 `'order_reporter_030500'@'%'`，练习密码使用 `'Reporter030500!'`。
2. 授予该账户对 `order_system_lesson_030500.*` 的 `SELECT, INSERT`。
3. 使用 `REVOKE` 精确回收 `INSERT`。
4. 最终账户只能保留该隔离数据库的 `SELECT` 权限。

不要使用 `ALL PRIVILEGES`、全局权限 `*.*` 或修改测试账户标识。
