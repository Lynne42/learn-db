# 练习：数据更新与删除

## 业务背景

在电商订单系统中，账户管理服务检测到一些测试和违规的垃圾账户。客服需要执行以下运维任务：
1. 用户 `'alice'` 因为违规操作，需要将其状态 `status` 置为 `0` (表示禁用)。
2. 对于系统中所有的已禁用账户 (`status = 0`)，需要从物理数据库中进行彻底删除。

为了保证操作符合生产安全规范，我们需要在开启 `sql_safe_updates` (安全更新模式) 的情况下安全地执行这些操作。

## 任务要求

请在 `exercise.sql` 中编写 SQL 语句，完成以下任务：

1. 编写一条 `UPDATE` 语句，将 `username` 为 `'alice'` 的用户的 `status` 变更为 `0`。
2. 编写一条 `DELETE` 语句，删除所有 `status = 0` 的用户。

> 💡 **提示**：为了确保在开启安全模式 (`SET sql_safe_updates = 1;`) 时不报错，你的 `DELETE` 语句应该使用可以走索引的列作为过滤条件（例如，使用主键限制 `id > 0` 并结合 `status = 0` 条件，由于 `id` 是主键索引，这可以有效绕过安全更新模式的安全拦截检查）。
