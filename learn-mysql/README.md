# 数据库实战学习项目 (learn-mysql)

这是一个由 `sk-db-learn` 技能自动生成的数据库实战与练习环境。本环境采用容器化隔离，数据会持久化保存在本地。

## 🚀 如何启动环境

本环境基于 Docker，启动前请确保你已经安装并启动了 Docker 引擎。

在当前目录打开终端，执行以下命令启动 MySQL 数据库：

```bash
docker compose up -d
```

*说明：第一次运行可能会拉取镜像，需要等待片刻。数据会持久化保存在当前目录下的 `data/mysql` 文件夹中。*

## 进入容器
使用命令行工具， 在项目根目录， 执行 
```sh
docker compose exec [容器名称: mysql-learn] bash
```

## 🛠️ 常用技能指令速查

在与 AI Agent 的对话中，随时可以使用以下指令来驱动你的学习进程：

- **`/db.next`**：🌟 **最常用的核心指令**。抽取并进入下一节课的讲解与练习。如果你上一节课还未完成或未通过，会提示你先完成。
- **`/db.check`**：当你完成了当前小节的 SQL 练习并保存在了 `exercise.sql` 中时，执行此指令让 AI 自动连接容器里的数据库进行自动化验证与批改。
- **`/db.progress`**：随时查看你当前学习的全局进度大纲，看看还有多少未解锁的关卡。
- **`/db.init <数据库名称>`**：如果你想再开一个并行的环境（比如以后想学 redis 或 postgres），可以用这个初始化。

## 📁 目录结构说明

- `docker-compose.yml`：Docker 环境编排配置文件。
- `progress.json`：你的私人学习进度记录，**请勿手动修改**。
- `data/`：数据库本地持久化目录（由 Docker 自动生成）。
- `schema/`：留给你自己保存历次建表/更新核心 SQL 的地方，作为日后的复习参考和环境重置。
- `lesson-xx/`：（未来生成）每次执行 `/db.next` 后自动生成的课件文档与练习题目录。
