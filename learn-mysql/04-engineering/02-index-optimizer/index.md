# 模块 04.02：索引工程化与优化器

> **模块定位**：04.01 解决“如何建立和读取索引”；本模块解决“为什么明明有索引，优化器仍可能不用，以及怎样以工程化方式修正 SQL、统计信息和索引设计”。

## 🎯 知识边界

**本模块覆盖：**

- SARGable 条件与函数、隐式转换、前导通配符导致的索引失效。
- `ANALYZE TABLE`、统计信息和 Cost Model 如何影响索引选择。
- `EXPLAIN`、`EXPLAIN ANALYZE`、索引提示的诊断边界。
- 索引冗余识别、命名、上线验证与回滚策略。

**本模块不覆盖：**

- B+Tree 页结构、聚簇索引和二级索引的物理基础（见 04.01）。
- 锁等待、死锁及事务隔离级别（见 04.03）。
