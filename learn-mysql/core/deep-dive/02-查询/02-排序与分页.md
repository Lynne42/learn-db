# 基础语句
```sql
SELECT id, preview_title, price 
FROM temp_products_preview 
ORDER BY price DESC, id ASC                -- 先按价格降序；价格相同时按 id 升序
LIMIT 20, 10;                              -- 跳过前 20 条，截取 10 条（即第 3 页，每页 10 条）
```


# 分页公式
假设每页显示 pageSize 条，当前是第 pageNo 页：
LIMIT (pageNo - 1) * pageSize, pageSize
