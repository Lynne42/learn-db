# 单行函数
## 字符串函数

| 函数 | 作用 | 示例 | 关键边界 |
|---|---|---|---|
| `CONCAT(a, b, ...)` | 拼接字符串 | `CONCAT('U-', id)` | 任一参数为 `NULL` 时结果为 `NULL` |
| `SUBSTRING(s, pos, len)` | 截取子串 | `SUBSTRING(order_no, 1, 8)` | MySQL 字符位置从 1 开始 |
| `TRIM(s)` | 去除首尾空格 | `TRIM(username)` | 不会删除字符串中间空格 |
| `REPLACE(s, from, to)` | 替换全部匹配片段 | `REPLACE(phone, '-', '')` | 是字面替换，不是正则 |
| `LENGTH(s)` | 返回字节数 | `LENGTH('中')` | `utf8mb4` 下字符可能占多个字节 |
| `CHAR_LENGTH(s)` | 返回字符数 | `CHAR_LENGTH('中')` | 适合计算用户可见长度 |

`LENGTH` 与 `CHAR_LENGTH` 不能混用。对 ASCII 字符，两者经常相等；对中文或 Emoji，字节数通常大于字符数。

| `ROUND(12.345, 2)` | 四舍五入到指定小数位 | `12.35` |

## 日期函数

| 函数 | 作用 | 示例 |
|---|---|---|
| `NOW()` | 当前会话时区下的日期时间 | `2026-07-27 15:00:00` |
| `DATE_FORMAT(dt, format)` | 格式化日期时间 | `DATE_FORMAT(created_at, '%Y-%m-%d')` |
| `DATEDIFF(a, b)` | 返回日期天数差 `a - b` | `DATEDIFF('2026-07-03', '2026-07-01') = 2` |
| `DATE_ADD(dt, INTERVAL n unit)` | 日期加指定间隔 | `DATE_ADD(created_at, INTERVAL 7 DAY)` |

# 类型转换 CAST
CAST()：ANSI 标准的强制类型转换

语法：
```sql
CAST( expression AS type )
```
- 语义理解：用关键字 AS 隔离“原始值”和“目标类型”，就像是在读英语：“把 X 转换为 Y 类型”。

| 类型 | 示例 | 用途 |
|---|---|---|
| `SIGNED` / `UNSIGNED` | `CAST(score_text AS UNSIGNED)` | 文本转整数 |
| `DECIMAL(p, s)` | `CAST(amount_text AS DECIMAL(10,2))` | 金额文本转精确数值 |
| `CHAR` | `CAST(id AS CHAR)` | 数值转字符串 |
| `DATE` / `DATETIME` | `CAST(date_text AS DATE)` | 文本转日期 |
| `BINARY` | `CAST(name AS BINARY)` | 二进制比较 |

# 条件/控制流函数

| 函数 | 作用 | 示例 |
| -- | -- | -- |
| `CASE` | 条件表达式，适合多分支规则 | 类比JS中的switch-case |
| `IF(condition, yes, no)` | 条件二选一 | MySQL 内部的简单判断 |
| `IFNULL(value, fallback)` | value 为 NULL 时返回 fallback | 单层 NULL 兜底 |
| `NULLIF(value, '')` | NULLIF：用来把特定值（如空字符串）变成 NULL, 参数A和B，如果A=B的时候，返回NULL， A !== B的时候，返回A |
| `COALESCE(a, b, c)` | 返回第一个非 NULL 值 | 多级字段回退，标准 SQL |

## CASE控制流
1. 检索型case, 每一个都是不同的条件
```sql
CASE
    WHEN score >= 90 THEN 'A'
    WHEN score >= 60 THEN 'PASS'
    ELSE 'FAIL'
END
```

2. 多值比较，类似于 Switch case 
```sql
CASE status
    WHEN 0 THEN 'DISABLED'
    WHEN 1 THEN 'ACTIVE'
    ELSE 'UNKNOWN'
END
```


## 函数与索引
1. 单行函数放在SELECT投影区，通常只增加返回行的 CPU 计算，就是在确认返回行的时候计算一次返回结果
2. 单行函数如果放在WHERE过滤条件中，可能需要逐行计算值，导致普通索引失效
