用于做统计分析（如：计算每个分类下的平均价格、商品总数）。

常用聚合函数：COUNT()（计数）、SUM()（求和）、AVG()（均值）、MAX()（最大值）、MIN()（最小值）、GROUP_CONCAT()。

```sql
-- 统计商品数量超过 50 个的“商品类型”，及其平均价格
SELECT 
    product_type, 
    COUNT(*) AS total_count, 
    AVG(price) AS avg_price
FROM temp_products_preview
WHERE is_deleted = 0                       -- 1. 先排除已被删除的数据
GROUP BY product_type                      -- 2. 按商品类型分组
HAVING total_count > 50;                   -- 3. 筛选出分组后数量大于 50 的类型
```

# GROUP_CONCAT
语法：
```sql
GROUP_CONCAT([DISTINCT] 字段名 [ORDER BY 排序字段 ASC/DESC] [SEPARATOR '分隔符'])
```
