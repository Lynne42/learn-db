# 覆盖索引（Covering Index）

如果一个二级索引的叶子节点中已经包含了 SELECT 所需的所有字段，MySQL 将直接把二级索引页中的数据返还给客户端，物理上彻底省去回表操作。这种关系叫覆盖索引（Covering Index）。

```sql
CREATE INDEX idx_cellphone_name ON users(cellphone, name);

SELECT cellphone, name
FROM users
WHERE cellphone = '13800000000';
```

覆盖索引会增加索引宽度、磁盘占用和写入维护成本。只对高频、稳定、回表代价明显的查询设计覆盖索引。

# 自检

- 判断查询所需列是否全部由索引提供。
- 理解 `EXPLAIN` 中 `Extra: Using index` 的含义。
- 在查询收益和索引维护成本之间做取舍。
