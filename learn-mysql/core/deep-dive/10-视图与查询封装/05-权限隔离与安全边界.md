# 10.05 权限隔离与安全边界

## 裁剪暴露范围

视图可以隐藏敏感列并限制可见行：

```sql
CREATE VIEW v_support_users AS
SELECT id, display_name, status, created_at
FROM users
WHERE deleted_at IS NULL;

GRANT SELECT ON order_system.v_support_users TO 'reporter'@'%';
```

报表账户只需要视图的 `SELECT` 权限时，不应同时授予底层表权限。

## 执行上下文

视图的 `SQL SECURITY` 决定权限检查上下文：

```sql
CREATE
    DEFINER = 'view_owner'@'localhost'
    SQL SECURITY DEFINER
VIEW v_support_users AS
SELECT id, display_name, status, created_at
FROM users
WHERE deleted_at IS NULL;
```

- `DEFINER`：以定义者权限访问底层对象。
- `INVOKER`：以调用者权限访问底层对象。

## 风险边界

- `DEFINER` 账户不存在会造成视图执行或迁移问题。
- 定义者权限过大会扩大视图缺陷的影响面。
- `SELECT *` 可能在底层表变更后形成不清晰的字段契约。
- 视图只能限制数据库访问路径，不能替代租户校验、审计和应用层授权。

生产环境应使用专用、最小权限且生命周期受控的定义者账户，并在迁移脚本中显式管理视图定义和授权。
